SEC/JUMP · UI REDESIGN

秒跳 · 主界面重设计 模拟稿

目标只有一个：一进来看一眼就知道「现在有没有在保护我」，以及今天省了我几次。 现在界面上 4 个开关、1 个状态卡、1 个按钮、10 行等宽字日志、1 段提示语，视觉重量几乎一样， 所以眼睛没有落点。下面 4 屏是候选方案，确定方向后我再改 layout、补图标、写代码。

相对现在的改动

  • 状态卡重做：左侧一句话状态，右侧 40sp 大数字，比原来 15sp 灰字更容易扫到
  • 三项系统权限从一行长警告，变成 三个小圆点，哪项红一眼看出
  • 4 个开关加 34dp 图标底，行高统一 62dp，分隔线左缩进对齐文字
  • 删掉主界面的 10 行等宽日志，改为「运行记录」二级页
  • 「规则管理」按钮变成列表行，和记录同一个卡片，少一个孤零零的按钮
  • 主开关关闭时，下面三项 置灰（视觉上真的「暂停」了）

实施成本

  • 纯 XML + Material3，不引入新依赖、不换主题
  • 4 个图标用 vector drawable（手写 path，约 40 行）
  • 运行记录页复用现有 SkipLog，新增一个 Activity，按「应用名 + 结果」重新排版
  • 长按标题进探测器、长按规则管理看学习记录、长按记录导出 —— 全部保留，只是不进界面
  • 预计 142 个单测不受影响（只动 UI 层）

需要你定的两件事

  • 选 A / B / C 哪个方向（我推荐 A）
  • 「运行记录」是 单独一页，还是做 从底部弹出的抽屉（不离开主界面）
说明：以上是 HTML 静态模拟，用来对齐视觉方向，不是最终像素。确认后我再改 activity_main.xml、MainActivity.kt、新增图标与记录页，跑一遍单测和真机回归再出 APK。
